# Fifidong Partner Landing Page

Static one-page site for potential Fifidong partners (EN/TH, profit calculator).

- `index.html` – the page, self-contained (images inline, fonts from Google Fonts)
- `Fifidong_Partner_Info_EN_TH.pdf` – printable partner info sheet, linked from the contact section
- `.nojekyll` – tells GitHub Pages to serve the files as they are

Hosted with GitHub Pages: Settings → Pages → Source "Deploy from a branch", branch `main`, folder `/ (root)`.
